# GitHub App Setup Guide - Check Runs

Este conteúdo foi consolidado no [README.md](./README.md), que agora é o documento principal do projeto.

Consulte o README para:

- criar o GitHub App com webhook já habilitado
- gerar a chave `.pem` em `Settings > Private keys`
- obter `APP_ID`, `INSTALLATION_ID` e `INSTALL_TOKEN`
- executar os scripts de criação, atualização e conclusão de `check_run`
- revisar troubleshooting e recomendações de segurança

- [GitHub App Documentation](https://docs.github.com/en/developers/apps)
- [Check Runs API](https://docs.github.com/en/rest/checks/runs)
- [Creating GitHub Apps](https://docs.github.com/en/developers/apps/building-github-apps/creating-a-github-app)
